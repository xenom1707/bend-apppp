Bend Calculator Android

זהו פרויקט Android Studio שמכיל את מחשבון הכיפופים כולו בתוך האפליקציה ועובד אופליין.

כדי ליצור APK:
1. פתח את התיקייה BendCalculatorAndroid ב-Android Studio.
2. המתן לסיום Gradle Sync.
3. Build > Build App Bundle(s) / APK(s) > Build APK(s).
4. קובץ ה-APK ייווצר תחת app/build/outputs/apk/debug/.

אין צורך ב-Python במחשב או בטלפון.
