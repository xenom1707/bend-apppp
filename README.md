# Bend Calculator Android

אפליקציית Android אופליין למאגר נתוני הכיפוף.

## יצירת APK בלי Android Studio

1. צור Repository חדש ב-GitHub.
2. העלה אליו את **תוכן התיקייה הזו** (לא את קובץ ה-ZIP עצמו).
3. פתח בלשונית **Actions** את `Build Android APK`.
4. לחץ **Run workflow** אם הבנייה לא התחילה אוטומטית.
5. בסיום, תחת **Artifacts**, הורד `BendCalculator-APK`.
6. בתוך קובץ ה-ZIP ש-GitHub מוריד נמצא `BendCalculator.apk`.
7. העבר/פתח אותו בטלפון ואשר התקנה ממקור לא מוכר אם Android מבקש.

האפליקציה עצמה עובדת אופליין ואינה דורשת Python.
